Module tokenizer 

Source
Expand description

Public tokenizer API split into small, tutorial-oriented modules.

This module is the curriculum-facing surface. It introduces explicit domain types so each API call reads as domain language instead of raw numeric/string plumbing.

The high-level flow is:

  1. build or load a vocabulary model,
  2. encode and decode text with predictable special-token handling,
  3. persist or restore learned artifacts.
