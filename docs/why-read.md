# Why Read These Papers?

## If You Are Reading Them for the First Time

Generative AI is moving quickly, and it is easy to rely on summaries of new model releases without understanding the underlying systems. Modern language models are built from specific engineering ideas: tokenisation, attention, decoding, data curation, efficient training, and alignment. Reading the primary papers helps turn those ideas into mechanisms you can reason about.

## If You Have Read Them Before

Context changes how these papers read. When "Attention Is All You Need" and "The Curious Case of Neural Text Degeneration" were published, the field looked very different. Reading them now makes it easier to see which ideas became standard practice, which assumptions aged well, and how later work responds to earlier limitations. The curriculum is designed to show that progression: one paper often clarifies the bottleneck that the next paper tries to address.
